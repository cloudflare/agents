Adds `createBrowserModule` (`agents/browser/computer`), which gives a `@cloudflare/computer` JavaScript backend the persistent browser as a `ws:browser` module, and deprecates `createBrowserTools` and `createBrowserRuntime`. See [From `exec` in a Computer Workspace](https://github.com/cloudflare/agents/blob/main/docs/agents/browse-the-web.md#from-exec-in-a-computer-workspace).
