`@cloudflare/shell` is deprecated. Use a `Workspace` from [`@cloudflare/computer`](https://github.com/cloudflare/computer) instead; `@cloudflare/think` and Agent Skills now accept only that. Files a Shell Workspace stored are not moved automatically. [Migrating to `@cloudflare/computer`](https://github.com/cloudflare/agents/blob/main/docs/shell/migrating-to-computer.md) documents both storage schemas and a script that copies a Shell workspace into Computer.
